SeriesContainer editor

Author your content as plain markdown — the files stay on your disk, in your repo. The renderer turns them into a static site.

Open connects to an existing project — pick a folder that contains a content/ folder (or the content folder itself). Create scaffolds a fresh content/ into the folder you pick, with either the Hub preset (a catalog of series) or the Book preset (one series, no hub). Opening never creates anything and creating never opens an existing site.

Uses the File System Access API — Chrome, Edge or Opera. Your last folder is remembered and re-opened when permission is granted again.

Create a project

Pick a folder, describe the site, then create. Everything is generated as markdown inside content/.

The scaffolding lands in <folder>/content/.
